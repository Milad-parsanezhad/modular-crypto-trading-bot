## Important limitation

Search-engine ranking cannot be guaranteed. Indexing and ranking are controlled by Google and depend on query competition, crawl/index timing, backlinks, user engagement and external authority. The project therefore optimizes for accurate technical relevance rather than keyword stuffing or unsupported profit claims.

## Update rule

After each major research stage:

1. update `docs/RESEARCH_CHANGELOG.md`;
2. update current status/decision if the evidence changed;
3. preserve the dated scientific result document and artifact identity;
4. link the new stage from the main README only after the result is stable;
5. never replace a negative result with a promotional claim.
