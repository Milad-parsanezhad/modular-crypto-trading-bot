## Scientific interpretation
1. CUSUM and Triple Barrier are **sampling/labeling tools, not alpha generators**. This run provides no evidence that applying them to the same weak OHLCV/technical feature family creates a profitable strategy.
2. Abstention reduced trading frequency but did not rescue the weak signal.
3. The negative result is useful: it prevents us from confusing a better research protocol with a predictive edge.
4. The next research value is in stronger information sources: order flow/microstructure, funding/basis/carry, point-in-time on-chain value/network activity, liquidity/cross-sectional structure, then regime-aware combination.
5. Robust statistical gates (CPCV, PBO, Deflated Sharpe, bootstrap/permutation, multi-model/multi-seed) remain mandatory before any profitability claim.
