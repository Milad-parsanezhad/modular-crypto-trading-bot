# v0.22 Vision Promotion Semantics

`NO_VISION_PROMOTION`: no encoder clears the frozen representation gates.

`RAW_ICT_DETECTOR_CANDIDATE`: a validation-selected raw candlestick/volume encoder also clears the untouched-test supported-label F1 gate. This permits downstream representation ablation only.

`AUGMENTED_REPRESENTATION_CANDIDATE_ONLY`: engineered structure channels improve the pre-registered outcome metric relative to the validation-selected raw detector but raw independent ICT recognition is not established.

`RAW_ICT_DETECTOR_AND_AUGMENTED_REPRESENTATION_CANDIDATE`: both representation hypotheses pass.

None of these statuses is a trading-strategy promotion. PAPER replacement and LIVE execution remain false until later multimodal, economic, external-replication, and forward-paper gates are separately satisfied.
