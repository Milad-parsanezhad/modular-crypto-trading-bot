## 1. Experiment A — Cost-aware alpha conversion

Source: CoinEx public spot 4h data, BTC/USDT and ETH/USDT.

The forecasting rule was frozen before the holdout: per-asset Ridge regression (`alpha=5.0`) on the project point-in-time feature set. The execution comparison used the same frozen forecast in both arms:

- naive: long when predicted next-bar return > 0;
- cost-aware: long only when predicted return exceeded `2 × one-way cost + 0.25 × training residual MAD`.

No execution threshold was tuned on the holdout.

### Aggregate holdout results

Holdout periods: **540**.

| Metric | Naive sign trading | Cost-aware abstention |
|---|---:|---:|
| Net return | **-7.48%** | **+0.048%** |
| Annualized return | -27.06% | +0.20% |
| Sharpe | -1.109 | +0.085 |
| Sortino | -1.442 | +0.035 |
| Max drawdown | -13.57% | **-1.32%** |
| Turnover sum | 114.0 | **10.0** |
| Explicit cost sum | 0.1368 | **0.0120** |
| Exposure | 51.39% | **1.48%** |

The execution filter dramatically reduced turnover and drawdown. It also changed the aggregate net result from materially negative to approximately flat/slightly positive.

However, the paired moving-block bootstrap did **not** establish a statistically secure positive mean edge:

- observed mean difference, cost-aware minus naive: **+0.0001303 per 4h period**;
- 95% moving-block bootstrap CI: **[-0.0003031, +0.0005508]**;
- the interval includes zero.

Therefore the frozen promotion decision is:

`NO_COST_AWARE_CONVERSION_EVIDENCE`

### Asset-level nuance

BTC naive trading was strongly negative (-19.28% net), while the cost-aware rule reduced the loss to approximately -0.21% with only four position transitions. ETH naive trading was +5.35% net; the cost-aware rule was +0.29% net with far lower turnover and drawdown.

This means the filter behaved primarily as a **risk/turnover suppressor**, not as a proven alpha generator. The aggregate economic improvement is scientifically interesting, but it does not clear the pre-registered bootstrap gate.

## 2. Experiment B — External Ichimoku/regime replication

Primary external venue: **OKX public spot 4h via CCXT**.

Assets: BTC/USDT and ETH/USDT.

The tested hypothesis was frozen from the v0.11 diagnostic result:

- base signal: `ichi_tenkan_kijun + ichi_price_kijun - ichi_cloud_width > 0`;
- conditioned signal: base signal active only in `HIGH_VOL` or `TREND_DOWN`;
- same point-in-time regime implementation as the project;
- no external-sample threshold tuning.

### Aggregate external-venue results

Evaluation periods: **1,748**.

| Metric | Plain Ichimoku | Regime-conditioned |
|---|---:|---:|
| Net return | -9.07% | **-2.79%** |
| Annualized return | -11.23% | -3.48% |
| Sharpe | -0.289 | **-0.175** |
| Sortino | -0.297 | **-0.105** |
| Max drawdown | -30.96% | **-17.99%** |
| Turnover sum | 108.0 | **38.0** |
| Explicit cost sum | 0.1296 | **0.0456** |
| Exposure | 35.15% | **10.58%** |

The frozen regime condition materially improved return, drawdown, turnover and exposure relative to plain Ichimoku, but the conditioned portfolio still had negative net performance.

Paired moving-block bootstrap on conditioned minus plain mean net return:

- observed mean difference: **+0.00002530 per 4h period**;
- 95% CI: **[-0.0002141, +0.0002566]**;
- the interval includes zero.

Therefore the external replication decision is:

`NO_EXTERNAL_REGIME_REPLICATION_EVIDENCE`

The v0.11 observation that HIGH_VOL/TREND_DOWN may matter was not disproved in the sense of direction — the conditioned rule improved several economic metrics — but it did **not** replicate strongly enough to support promotion under the pre-registered criteria.

## 3. Combined scientific interpretation

v0.18 produced two important non-promoted findings:

1. **Cost-aware abstention appears economically useful as a risk/turnover control**, reducing aggregate turnover by about 91% and maximum drawdown from about -13.6% to -1.3% in Experiment A; however, the paired bootstrap interval still included zero, so a positive alpha-conversion claim is not authorized.
2. **The frozen regime condition improved plain Ichimoku on an external venue**, reducing turnover, drawdown and the magnitude of loss; however, the conditioned rule remained net negative and the bootstrap edge was statistically inconclusive.

These outcomes are consistent with the project’s central evidence philosophy: an economically attractive directional change is not promoted unless the pre-specified statistical and net-performance gates are satisfied.
