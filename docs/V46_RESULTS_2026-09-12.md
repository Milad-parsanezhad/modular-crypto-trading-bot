## Scientific interpretation

v0.46 rejects the narrow hypothesis that simply splitting the TIME terminal class into positive and non-positive timeout states is sufficient to solve the current representation/calibration problem.

The split appears economically relevant—the aggregate expectancy and PF moved in the right direction—but the improvement is not temporally robust and is not accompanied by better common-space probability skill. This is precisely why the project requires joint forecast and economic gates rather than selecting a model from aggregate return alone.

The current evidence therefore suggests:

1. TIME economic heterogeneity is real, as v0.45 showed;
2. a static four-class terminal encoding alone is insufficient;
3. the remaining bottleneck still involves probability reliability and temporal/state dynamics;
4. model capacity should still not be increased merely to rescue the failed label representation.
