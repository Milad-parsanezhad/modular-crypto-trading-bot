# راهنمای اجرای ربات

این نسخه یک سامانه پژوهشی قابل اجرا برای آموزش مدل، بک‌تست و معامله آزمایشی است. نتیجه سودآوری واقعی هنوز به دست نیامده است.

## نصب روی ویندوز

Python 3.11 یا جدیدتر نصب کن. مخزن را دانلود کن و PowerShell را داخل پوشه آن باز کن:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install torch --index-url https://download.pytorch.org/whl/cpu
python -m pip install -e ".[research,test]"
python -m pytest -q
milad-bot demo --output outputs/demo-001
```

اگر فعال‌سازی محیط در PowerShell محدود بود، بدون تغییر سیاست سیستم می‌توان از ` .venv\Scripts\python.exe ` به‌جای `python` استفاده کرد و دستورات برنامه را با ` .venv\Scripts\python.exe -m milad_trader.cli ` اجرا کرد.

دستور `demo` داده مصنوعی می‌سازد و مسیر آموزش تا ارزیابی را آزمایش می‌کند. اعداد آن قابل استفاده به‌عنوان نتایج بازار در پایان‌نامه نیستند.

## داده واقعی و آزمایش

```powershell
milad-bot fetch --exchange coinex --symbol BTC/USDT --timeframe 4h --since 2024-01-01T00:00:00Z --until 2026-01-01T00:00:00Z --output data/raw/coinex-btc-4h.csv
milad-bot research --config configs/research_4h.toml --data data/raw/coinex-btc-4h.csv --output outputs/btc-development-001
```

تاریخ‌ها نمونه تنظیم اجرای توسعه‌اند و به‌معنای تصویب بازه نهایی پایان‌نامه نیستند. برای ETH از نماد `ETH/USDT`، فایل داده مستقل و `configs/research_eth_4h.toml` استفاده کن. اتصال CoinEx در محیط ساخت با خطای شبکه مواجه شد؛ بنابراین دریافت واقعی این بازه در این نوبت تأیید نشده است.

فایل تنظیمات تعداد کندل‌های آموزش، اعتبارسنجی و آزمون، seedها، مدل‌ها، کارمزد و ریسک را تعیین می‌کند. اگر داده کافی نباشد، برنامه با پیام روشن متوقف می‌شود. خطا را با اضافه‌کردن داده ساختگی به داده واقعی رفع نکن.

## خروجی‌ها

| فایل | معنی |
|---|---|
| `manifest.json` | تنظیمات، مشخصات و هش داده، نسخه کتابخانه‌ها و اثرانگشت کد |
| `metrics.csv` | معیارهای هر مدل، seed، پنجره و وضعیت ویژگی‌های ایچیموکو |
| `*_equity.csv` | مسیر ارزش کل حساب |
| `*_fills.csv` | معاملات شبیه‌سازی‌شده همراه قیمت، هزینه و دلیل خروج |
| `regimes.csv` | عملکرد شرطی در رژیم‌های تخمینی بازار |
| `cost_sensitivity.csv` | حساسیت مدل‌های نظارتی به هزینه بیشتر |
| `bootstrap_intervals.json` | بازه‌های توصیفی اختلاف بازده؛ بدون اصلاح آزمون‌های متعدد |
| `*.joblib` و `*_agent.zip` | مدل‌های ذخیره‌شده برای ادامه کار آزمایشی |

خروجی‌ها و مدل‌های حجیم به‌صورت پیش‌فرض وارد GitHub نمی‌شوند. گزارش منتخب، پس از بررسی و با برچسب نوع داده، در `reports` ثبت می‌شود. برای هر آزمایش نام پوشه جدید بده.

## اجرای خودکار آزمایشی

```powershell
milad-bot paper-watch --bundle outputs/btc-development-001/fold2_seed42_random_forest_ichi.joblib --exchange coinex --state outputs/paper-btc/account.json --poll-seconds 60
```

این دستور فقط حساب آزمایشی را به‌روزرسانی می‌کند. نخست یک تصمیم برای کندل بعد ثبت می‌شود؛ پس از بسته‌شدن کندل بعد، معامله با فرض قیمت بازشدن و قواعد توقف شبیه‌سازی می‌شود. کلید صرافی لازم نیست. دستور بالا به انتخاب یک مدل نمونه اشاره دارد، نه توصیه به برتری آن. برای توقف از Ctrl+C استفاده کن.

اگر داده عقب افتاده، تاریخچه تغییر کرده یا چند کندل از دست رفته باشد، اجرا متوقف می‌شود تا حساب آزمایشی بررسی شود. فایل checkpoint را برای تغییر دادن زیان یا سود ویرایش نکن. مدل ذخیره‌شده را فقط از منبع مورداعتماد بارگذاری کن.

نوبیتکس، سفارش واقعی، برداشت وجه و ارتباط تلگرام در این نسخه پیاده‌سازی نشده‌اند. کدهای قدیمی حاوی بخش‌های تکمیل‌نشده بودند؛ وضعیت واقعی ماژول‌ها در نقشه راه ثبت شده است.
